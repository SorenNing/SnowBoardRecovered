# SnowBoardRecovered

Static reconstruction of SnowBoard 1.5.37-Beta4 reduced to a runnable engine:
creates the theme directory, indexes `<Theme>/IconBundles/<bundle-id>@3x.png`,
installs icon hooks and logs to `/var/mobile/Library/SnowBoardRecovered.log`.

Build: GitHub Actions (macOS runner, roothide Theos, arm64e).
Not the original source; research build.
